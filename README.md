## התקנה כאפליקציה בנייד

פתחו את הכתובת בדפדפן ← תפריט ← **הוספה למסך הבית**.

## אבטחה

- **CSP** — `<meta http-equiv="Content-Security-Policy">` מגביל את כל המקורות ל־`'self'` בלבד (אין CDN, אין scripts/styles חיצוניים). שימו לב: `<meta>` CSP לא יכול לשאת `frame-ancestors` — אם צריך גם `X-Frame-Options`/headers אמיתיים, יש לארח בפלטפורמה שתומכת ב־headers מותאמים (כגון Cloudflare Pages / Netlify עם קובץ `_headers`), ש־GitHub Pages אינה תומכת בהם.
- **פלט לתוך הדף** — טקסט האפשרויות (`esc()`) עובר escaping מלא. הסברי השאלות והכרטיסיות (`e`/`w`/`f`/`b`) עוברים דרך `safeHTML()` — פונקציית allowlist שמשאירה רק תגיות עיצוב מוגבלות (`b`, `code`, `br`, `i`, `em`, `strong`) ומסננת הכל מלבדן, כהגנת עומק למקרה שבו תוכן שאלות חדש ייכתב בעתיד בלי בדיקה קפדנית.
- **אחסון מקומי עמיד** — טעינת המצב מ־`localStorage` מנורמלת (`Store.normalize`) כך שערך פגום/חלקי לא יקריס את האפליקציה, אלא "מתוקן" בשקט לערכי ברירת מחדל.
- **Service Worker** — cache-first עם שם גרסה (`CACHE`) ב־`sw.js` שיש להעלות בכל שחרור תוכן/קוד, אחרת משתמשים חוזרים עלולים להמשיך לקבל גרסה ישנה מהמטמון לזמן מה.
